# Bank Management System 

## Overview
The **Bank Management System** is a desktop application designed to streamline banking operations. The system provides tools for managing users and customers efficiently while maintaining a secure environment. It includes essential features like user and customer management, transaction handling, and activity tracking.

---

## Features

### User Management
- **Add New Users**: Create user accounts with specific roles and permissions.
- **View All Users**: Display a list of all registered users.
- **Edit User Information**: Update user details and modify permissions as needed.
- **Delete Users**: Remove user accounts securely.
- **Search Users**: Find users quickly using a search functionality.
- **User Activity Logs**: View a list of all users who have logged into the system.

### Customer Management
- **Add New Customers**: Register new customers with their account details.
- **View All Customers**: Display a comprehensive list of all bank customers.
- **Edit Customer Information**: Update customer details, including account information.
- **Delete Customers**: Remove customer records from the system.
- **Search Customers**: Locate customer records quickly.

### Transaction Management
- **Funds Transfer**: Transfer funds between accounts securely.
- **Transaction History**: View all transactions performed in the system.
- **Deposit Funds**: Add a specific amount to a customer's account.
- **Withdraw Funds**: Deduct a specific amount from a customer's account.

---
